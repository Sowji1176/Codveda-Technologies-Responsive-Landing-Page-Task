## About the Project

Nexora is a modern, responsive landing page developed using HTML5, CSS3, and JavaScript as part of **Task 1: Responsive Landing Page** for the Codveda Technologies Front-End Development Internship.

The project focuses on responsive layouts, modern UI design, accessibility, intuitive navigation, and smooth interactions across desktop, tablet, and mobile devices.

## Key Features

* 🧭 Responsive Navigation Bar
* ✨ Modern Hero Section
* 💡 Feature Cards
* 📱 Mobile-Friendly Layout
* 🎨 Gradient Styling and Animations
* 🖱️ Interactive Navigation
* 🌊 Smooth Scrolling
* ♿ Accessibility-Friendly Design
* 📩 Contact Section
* 🦶 Footer with Navigation Links
